# Protocol v1 frozen by B0

Canonical structural schemas are generated from `backend/app/contracts/` into `v1/*.schema.json`. `v1/fixtures.json` is the shared valid/invalid corpus. Protocol version 1 (drawing operations), wire version 1 (HTTP NDJSON envelopes) and audio protocol version 1 are separate version axes.

Six existing operation discriminants are preserved: `section.add`, `node.add`, `edge.add`, `node.update`, `edge.update`, `entity.delete`. The plan's reference to “seven” operations is a counting typo; no new operation was invented. Coordinates are section-local world units, section origins are world-space, and the 64-unit placement gap stays frontend-owned. Backend code must not calculate layout or use an emitted operation as authoritative scene state.

The backend generation request requires full context and mandatory `source`, `locked`, `revision` on edges, matching nodes. The frontend context builder, schemas and fixtures were amended together. Missing edge protections are rejected rather than inferred. Drawing schemas remain unchanged.

JSON Schema encodes structure, types, bounds, discriminants, unknown-key rejection, reserved IDs, nonempty patches/labels and mutually exclusive placement. Runtime validators additionally enforce ID/source identity, globally unique entities, same-section references, combined entity caps, revision bounds, selection validity, equal circle dimensions, transcript segment uniqueness and time ordering. These relational rules are not fully expressible in ordinary JSON Schema; accepting structure alone does not authorize dispatch. Python and TypeScript run the same relational fixtures. Optional fields are omitted, not explicitly null; `activeSectionId` is nullable.

HTTP generation events are NDJSON: exactly one UTF-8 JSON envelope per line. `sequence` starts at 1 and advances for every event, including warnings and terminal events. Original sequence numbers pass unchanged to the scene dispatcher; gaps are valid in a replay excerpt. B3 persists events before emitting them. The model never generates envelopes or transport metadata. A replay keeps its original request ID, epoch, base revision and sequences. EOF without a terminal is an interruption. Validated prefix operations survive a failed request. Exactly one of `completed`, `failed`, `cancelled` is terminal.

The frontend `GenerationTransport.generate()` returns `AsyncIterable<GenerationEvent>`. Its mock wraps `RawMockFixtureTransport` through `adaptRawFixtureTransport`, where raw model NDJSON is decoded, validated and namespaced. Byte fixtures are test/parser inputs only. The consumer validates envelopes and metadata; it does not prefix canonical HTTP IDs or renumber operations. B3's HTTP adapter decodes bounded UTF-8/NDJSON records, validates identity/revision/sequence/terminal events, and yields typed events unchanged. Stream byte statistics measure serialized event sizes rather than raw model chunk sizes.

Audio contract: start → ready → ordered binary PCM/control messages; do not send PCM before ready. Format is 16 kHz, mono, signed 16-bit little-endian. Frames must be nonempty, even-sized and at most 32,000 bytes (one second). `finish` flushes; `abort` discards. Segment revisions keep their ID, and a final segment is emitted once. B1 owns timing/order/state enforcement and resampling; B0 publishes types and frame validation only.

B3 session endpoints: create body `{sessionEpoch?, profile?, diagramProfile?}`; result `{sessionId,sessionEpoch,profile,diagramProfile,configurationFingerprint}`. Optional initial `sessionEpoch` defaults to zero; it aligns a new server session with a browser board already restored/imported at a later epoch. Existing epoch ownership cannot be overridden: reset increments it, and old requests/streams are rejected. GET session and DELETE session require the current `sessionEpoch` query parameter. Cancel/reset bodies carry `{sessionId,sessionEpoch}`. Replay requires `sessionId`, `sessionEpoch`, and optional `after` (default zero). Session IDs are unguessable local capabilities; supplied HTTP origins and mandatory WebSocket origins are checked. Error envelopes are `{error:{code,message}}`; raw provider bodies are not exposed. Unknown/expired session/replay returns 410, stale epochs/fingerprint conflicts return 409. B3 replaces B0's 501/1013 stubs with live endpoints.

Provider protocols live in `app.contracts.interfaces`. Speech has ordered/backpressured `push_audio`, one `events()` consumer, graceful `finish` and idempotent aborting `close`. Diagram `stream()` immediately returns an async iterator of append-only `TextDelta`, cumulative `Usage`, exactly one validated `Finished`; EOF alone is not successful completion. Per-request iterator closure must not close shared clients. `aclose()` is application shutdown cleanup. Errors use `ProviderError` with normalized code, safe message, retryability, retry-after and upstream request ID. No SDK imports are present in shared contracts.
